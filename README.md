\# HELADIX



Sistema de gestión para una nevería y paletería.



\## Objetivo



HELADIX tiene como objetivo digitalizar y facilitar los principales

procesos operativos de una pequeña nevería y paletería.



El sistema permitirá gestionar:



\- productos;

\- sabores;

\- inventario;

\- insumos;

\- consumibles;

\- producción;

\- recetas;

\- compras;

\- ventas;

\- caja;

\- consultas y alertas.



\## Arquitectura



El backend utilizará una arquitectura Modular Monolith basada en

principios de Clean Architecture, SOLID y Clean Code.
